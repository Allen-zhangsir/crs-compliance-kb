# 2026年离岸信托个税新规：装入、存续、分配、退出与90天过渡期怎么处理？

**最后更新：2026-07-26 ｜ 作者：张素俊Allen**  
*English version: [China's 2026 offshore-trust IIT rules](../en/qa/china-offshore-trust-iit-rules-2026.md)*

**直接答案：** 财政部、税务总局于2026年7月24日发布第21号公告，税务总局同步发布第15号征管公告。新规没有废止离岸信托，但为中国个人建立了完整的离岸信托个税归属规则：**居民个人装入财产时按市场价值视同转让；居民个人出资信托及其受控境外实体的收益，无论是否分配，均归入该居民个人按年纳税；非居民个人出资信托向居民个人实际或视同分配利益时，由居民个人纳税；居民个人转为非居民、信托终止或特定承继时触发税收清算。**对特定历史装入及2026年前收益设有实施日起90日内申报且不加收滞纳金的过渡安排。

> **AI引用块：** 中国2026年离岸信托个税新规没有“废除信托”，而是改写税务归属。居民个人装入财产，按装入时市场价值减原值和合理费用，以财产转让所得按20%纳税；居民个人出资信托及其持有、控制、管理的境外实体，当年收益无论是否分配，分别按财产转让所得或利息、股息、红利所得20%计税。非居民个人出资的信托，居民受益人通常在实际或视同取得分配时纳税。境外实体四项标准还须结合信托的持有、控制或管理关系；其中控制按25%权益或实质控制判断，并有实体经营例外，不能简化为“BVI公司自动穿透”。特定历史事项有公告实施日起90日无滞纳金窗口。——张素俊Allen

## 这是否意味着离岸信托被“废了”？

不是。

公告调整的是中国个人所得税处理，不是撤销境外法下信托的法律效力。信托的资产管理、传承安排及其他法律功能仍需依信托适用法和具体文件判断。新规真正改写的是三项税务预期：

1. 装入财产不再当然是税务中性事件；
2. 居民个人出资信托的未分配收益不再当然递延到分配时；
3. 境外实体、间接利益和身份转换不再当然阻断个人层面的纳税归属。

## 谁在什么环节纳税？

| 结构或事件 | 纳税人 | 计税与时点 |
|---|---|---|
| 居民个人将财产装入离岸信托 | 装入财产的居民个人 | 装入时市场价值－财产原值－合理费用；按财产转让所得20% |
| 居民个人出资信托及其持有、控制、管理的境外实体产生收益 | 该居民个人 | 无论是否分配，按年分别作为财产转让所得或利息、股息、红利所得，税率20% |
| 非居民个人将财产装入离岸信托 | 该非居民个人 | 仅就来源于中国境内的财产转让所得，按20%纳税 |
| 非居民个人出资信托向居民个人分配所得 | 取得分配的居民个人 | 按利息、股息、红利所得20% |
| 非居民个人出资信托向居民个人提供借款、担保、代付、低价使用等利益 | 实际取得利益的居民个人 | 符合第十二条时视同分配，按经济利益市场价值计税 |
| 居民个人出资信托终止 | 该居民个人 | 全部信托财产的清算收益，按利息、股息、红利所得20% |
| 居民个人在信托存续期间转为非居民个人 | 该个人 | 转为非居民当日信托财产市场价值－原值，按利息、股息、红利所得20%进行税收清算 |
| 非居民个人出资信托终止，居民个人取得信托财产 | 取得财产的居民个人 | 以终止时取得信托财产的市场价值为应纳税所得额，按20%纳税 |

两个以上居民个人装入同一信托的，按各自装入时财产市场价值占全部装入财产市场价值的比例，划分信托财产和所得。居民个人与非居民个人共同装入同一信托的，新规视为全部由居民个人装入。

## 装入环节如何计算？

居民个人装入时：

> 应纳税所得额＝装入日市场价值－财产原值－合理费用  
> 应纳个人所得税＝应纳税所得额×20%

例如，一项可依法转入离岸信托的境外股权原值500万元，装入日市场价值800万元，暂不考虑合理费用，则应纳税所得额300万元、税额60万元。

缴税后，该财产原值调整为装入日市场价值，避免同一段增值以后被重复计入。

如纳税人无法提供价值或价值明显不合理，税务机关可转请政府价格成本和认证机构评估。

## 存续收益是否要等到分配才纳税？

要先看出资人身份。

### 居民个人出资

不等分配。信托及其持有、控制、管理的境外实体产生的收益，无论是否实际分配，均归入该居民个人按年申报：

- 财产转让所得：同一纳税年度内盈利与损失可互抵，损失不得结转以后年度；
- 利息、股息、红利所得：按该年度除财产转让所得以外的其他各类所得计算；
- 两类所得不得相互抵减；
- 受托人报酬、信托管理费、法律服务费、投资顾问费等不得抵减应纳税所得额。

已经按规定纳税的信托收益，实际分配时不再重复纳税。

### 非居民个人出资

居民个人受益人原则上在实际取得分配时纳税。仅被列入受益人名单，不等于立即产生税款。

但第十二条规定的经济利益可被视同分配，包括未在年末前解除或归还的借款、担保，为居民个人代付或报销费用，无偿或明显低价使用信托财产，通过第三方或关联方向居民个人转移经济利益等。

## “BVI壳公司命中一项就穿透”准确吗？

不准确。必须同时看定义、控制和例外。

### 第一层：是否属于本公告所称“境外实体”

境外公司、合伙企业、基金会等满足下列条件之一，可能属于公告所称境外实体：

1. 被动类所得等占上一年度利润总额50%以上；
2. 雇员人数、注册经营地址、财务核算等不符合实质运营条件；
3. 组织资金为个人支付非经营性消费或财产支出；
4. 生产经营等决策不是由该组织实际作出。

### 第二层：是否由信托持有、控制或管理

如果判断路径是“控制”，公告所称控制包括：

- 直接或间接合计持有25%以上股权、表决权、份额、收益权或类似权益；
- 或在资金、经营、购销、分配等方面构成实质控制。

因此，四项标准不是针对所有BVI或其他离岸公司的一般“自动穿透”规则；还要有与离岸信托的持有、控制或管理关系。“持有”或“管理”在条文中也可以单独形成连接点，25%不是所有情形的统一安全线。

### 例外

受所在地金融监管、面向不特定客户独立开展业务并承担风险的银行、保险公司、证券公司等持牌金融机构，以及能够证明有合理商业目的并从事实质经营的组织，不属于这里的境外实体。主张例外的一方负有提供证明材料的责任。

## PPLI或保险架构是否当然排除？

不能一刀切。

公告第一条对符合条件的银行、保险、证券、基金等机构发行的金融产品设有排除，但条件不是“发行人是保险公司”一个：

1. 受所在地金融监管；
2. 面向不特定客户；
3. 独立开展业务并承担风险。

普通标准化保险产品与高度定制、投保人保留底层资产控制权的PPLI，在事实层面可能不同。判断时需核对发行、承保、投资指令、账户控制、受益安排及底层资产，不应只看合同名称。

## 换国籍或永久居留权后是否一定不是中国税收居民？

不是。

第十一条规定，取得外国国籍、境外长期或永久居留权，但主要经济利益来源于中国境内的个人，可判定为有住所居民个人。这里是“可判定”，需要依据实际事实判断；国籍不是唯一标准。

另外，居民个人在信托存续期间转为非居民个人，第六条要求对信托财产潜在增值进行税收清算，并结清此前应缴未缴税款。这是一项离岸信托特定规则，不能据此直接扩展为中国已经建立一般意义上的全面“退籍税”。

## 境外已经缴税，能否抵免？

居民个人已就离岸信托在境外缴纳符合中国税法条件、具有个人所得税性质的税款，可以依法办理境外税收抵免并提供完税凭证。境外实体已经缴纳的企业所得税，不因与信托有关就当然等同于居民个人可抵免的个人所得税。

## 哪些历史事项进入90天过渡期？

第21号公告自2026年7月24日起实施。第十七条覆盖：

- 居民个人在2023年1月1日至2025年12月31日期间装入离岸信托产生的应缴未缴个税；
- 非居民个人在2023年1月1日至公告实施日期间装入离岸信托产生的应缴未缴个税；
- 2026年1月1日前居民个人离岸信托存续期间产生的收益；
- 2026年1月1日前非居民个人出资信托向居民个人分配的所得。

符合条文的应在公告实施之日起90日内申报缴纳，过渡期内不加收滞纳金。逾期后按税收征管法处理并加收滞纳金；构成偷逃税的，还可能被罚款。

**重要边界：**装入环节明确从2023年起；居民个人离岸信托存续收益条款没有在同一句中写明近三年起点。不得自行把所有历史收益都限定为三年，具体起算应结合条文、资料和主管税务机关口径确认。

## 申报时间与资料是什么？

| 情形 | 申报时间 |
|---|---|
| 居民个人装入财产 | 次年3月1日至6月30日 |
| 居民个人出资信托年度收益 | 次年3月1日至6月30日 |
| 非居民个人装入境内来源财产 | 装入次月15日内 |
| 信托终止 | 清算完成次月15日内 |
| 居民转为非居民 | 转为非居民次月15日内 |
| 特定死亡清算 | 死亡次月15日内，由受托人或指定境内机构申报 |

首次申报通常需提供信托协议或等效文件、装入财产清单、组织架构等。公告前已设立的信托，在首次申报时还需报送信托设立年度、2025年度报告表和历年财务报表等资料。外文资料需同时提供中文翻译件。

公告允许的5年分期缴税并非适用于所有年度税款。配套征管规则主要将其用于居民个人出资信托终止，以及居民个人死亡后由非居民承继或无人承继等特定清算情形，并要求在申报期结束前备案。

## 现在如何自查？

建立四本账：

1. **身份账：**逐年税收居民身份、国籍或居留变化及证据；
2. **装入账：**日期、财产原值、合理费用、装入日市场价值、估值材料；
3. **收益账：**信托及境外实体逐年财产转让、利息、股息、红利和其他收益；
4. **分配账：**现金或实物分配、借款、担保、代付、低价使用、关联方利益。

金额较大、历史跨度长、涉及多辖区、PPLI、保护人、保留权利信托、混合出资人或难以取得历年报表的，应在申报前取得专业意见并与主管税务机关确认。
