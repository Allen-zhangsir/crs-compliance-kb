| [已经买了的香港保险，需要补办备案吗？（837号令）](qa/decree-837-hk-insurance-filing.md) | 不需要——无溯及条款；框架是"存量安全，增量看细则" |
| [对外投资备案和 CRS 申报有什么区别？](qa/filing-vs-crs-reporting.md) | 备案管资金出境的门，CRS 管资产已在境外的门，互不豁免 |
| [香港保单收益要交20%个税吗？（2026年8月最新）](qa/hk-policy-dividend-tax-2026.md) | 分四笔钱、三个层次：理赔金法条层法定免税；分红/退保增值段法理层未定＋执行层个案在征（财新2026-08-05：京杭个案20%、"尚不具普遍性"）；预缴利息依据最扎实。含**「定性梯度」**：最清楚的两笔在两端（理赔金明文免税／预缴利息本金—孳息结构完整），最模糊的两笔在中间（分红、退保增值段）；**定性清楚≠一定被征≠现在被普遍征**。另含香港保监局2026-08-06回应完整两句与证券时报实地核实结果 |
| [香港储蓄险提取时，到底要不要交个税？](qa/hk-savings-policy-withdrawal-tax.md) | 看取哪种钱：理赔金免税、持有未提取不征、退保增值段定性未明；申报≠征税 |
| [香港重疾险定义9月1日统一，我的保单受影响吗？](qa/hk-ci-definition-standardization-2026.md) | 旧保单不受影响（准则6.1/6.3条写死）；理解须抓原文**三个限定词**：自愿（2.2条·行业自律非监管强制）、最低标准（3.2条）、只管新品（6.1条）；**续保是例外**（6.2条"可自行决定"）；3.6条明载"保费中立"；方向未公布，但2.1条自述参考内地既有定义、4.5条又排除内地CCMD编码——**参考≠照搬** |
| [内地重疾险 vs 香港重疾险，怎么比才不被带偏？](qa/mainland-vs-hk-critical-illness-comparison.md) | 比的是"确诊定义/理赔条件/币种与法域"，不是单看保费高低 |
| [香港保险公司会不会倒闭？偿付能力充足率到底该怎么看](qa/hk-insurer-solvency-ratio-how-to-read.md) | 不能——相对指标+2024-07制度切换（同一保司同日337%/289%两口径）；看四维：五年趋势/主体评级/核心资本/再保+条例46条转移机制 |
| [香港分红险的分红实现率和偿付能力，怎么看？](qa/hk-dividend-fulfilment-ratio-and-solvency.md) | 实现率看长期履约、偿付能力看公司稳健；两个指标各答一个问题 |
| [香港保险的三个公开数字怎么用？](qa/hk-insurance-three-numbers-check.md) | 偿付率答"会不会倒"、实现率答"兑现了多少"、演示上限答"最高画到哪"（6.0%/6.5%）；官方实证：同一保司90天从174%到837%（注资）——偿付率是时点数，不是排行榜 |
| [香港分红险演示的收益，能拿到吗？（分红实现率／GL16）](qa/gl16-fulfilment-ratio-disclosure-guide.md) | 每年6-30前统一披露、三类红利分列、覆盖2010年起产品；无绝对及格线——三维判读：时间深度×产品口径×自身需求；GL34分红基金隔离是治理保障、非破产隔离 |
| [四大险种都断保了，先恢复哪一个？](qa/lapsed-policies-which-to-reinstate-first.md) | 先查长期险2年复效倒计时；默认意外险当天、医疗险本周、重疾定寿走复效 |
| [家庭保单怎么管理才不会断保？](qa/policy-management-three-stages.md) | 投保前—投保中—投保后三阶段框架：台账＋缴费提醒＋年检 |
| [在中国，金融机构用 AI 做保险与合规业务，监管有哪些硬要求？](qa/ai-in-insurance-china-regulatory-requirements.md) | 金发〔2026〕8号（2026-06-18，八节32条）：**谁使用谁负责**；**承保理赔属高风险应用**须风管委批准（十六条）；关键决策**须设人工复核节点**并留存原始数据/推理路径/阈值触发记录（二十二条）；个人信息不得用于生成式AI训练；**适用对象限持牌机构** |
| [怎么判断一个保险顾问是不是站在我这边？](qa/how-to-tell-if-your-adviser-is-on-your-side.md) | 不靠态度靠**利益可见性**——态度好/回复快/资料全在两种动机下表现相同，无区分力；有区分力的只有"利益冲突节点上的实际选择"：**主动披露"怎样对我更有利"＋选了对自己不利的那项**。六问检验，最狠一问"现在投保和等一等对你分别有什么影响"；边界：**说得清合同，说不清身体** |
| [买了意外险，出事却可能不赔？先查「职业类别」这一项](qa/accident-insurance-occupation-class.md) | 第一道闸不是保额是**职业类别**，且**判两次**：投保时按申报的判、出险时按实际在做的判。**没有全国统一分类表**——"某职业是几类"脱离产品不成立。**「类别漂移」**：工作变了类别就动，超出承保范围又未通知，保单**不会给任何提示**地停止响应 |
| [留学回国后医保要等3个月还是6个月？先看你断的是哪几年](qa/returnee-medical-insurance-waiting-period.md) | **规则不溯及2025年之前**，境外断缴的旧年份不计入，四年/六个月的下限**最早2029年才可能出现**；多数人的3个月来自"或"字——**没踩上集中参保窗口**，与断缴年限无关。**「择期成本」是免费的变量** |
| [网上的保险产品对比表，比的是不是我要买的那一款？](qa/product-comparison-table-version-check.md) | **那张表很可能是对的**：表上是**品牌**，你买的是**版本**——同一系列常有多版，保障年期／附加保障／保费结构各异。两个数校验：**年缴保费＋保障年期**。"保费一致、回报不一致"＝同产品不同签发日，保证数字是合同、预期数字会更新 |
| [别人给我的保险数字，怎么自己核一遍？（四问法）](qa/how-to-verify-an-insurance-number.md) | 四问：谁说的／基数是什么／有几个限定词／哪个版本。**产品手册是官方出品，但它不是合同**——条款编号与生效日期只在保单条款里。**「分母错配」**：百分比只在基数相同时才可比 |
| [我的保费是保证不变的吗？在建议书哪里能找到答案](qa/is-my-insurance-premium-guaranteed.md) | 「年保费×缴费年期＝总投入」**只在保费率保证的产品上成立**；非保证的，那个数是**首年价格不是长期成本**。查两处：首页摘要表的**独立字段**、页脚**编号注释**。找到后再看它披露了几面：频率／触发因素／调整方式（"划一调整特定风险级别"**对投保人有利**）／有无上限。**它是唯一一项会改变表上所有数的变量，而多数对比表不为它设列** |
