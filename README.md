| [业务员离职了，我的保单谁管？](qa/agent-left-who-services-my-policy.md) | **合同从一开始就不是和业务员签的，是和保险公司签的**——业务员的法律地位是**代理人不是合同当事人**。《保险法》**第一百二十七条**第一款：代理人在授权范围内办理业务的行为**由保险人承担责任**；第二款连**代理权终止后**的情形都兜住了：使投保人有理由相信其有代理权的，**该代理行为有效**，保险人可另行追究越权代理人——**那是公司与他之间的事，不由投保人承担**。效力中止事由（第三十六条）是列举式的，**离职不在其中**。⚠️ 本条解决**责任归属不是服务安排**：「须在多久内指派新服务人员」**未取得一手依据，标 [待核实]**。**最实用的一句：不管有没有人联系你，你都可以直接找公司官方渠道——你从来不需要通过某个特定的人才能行使权利** |
| [我买的保险停售了，保单会受影响吗？](qa/product-discontinued-what-happens.md) | **停售 =「新客户买不到了」，不是「老客户的合同变了」**。《保险法》**第三十六条**列举的效力中止情形是**欠交保费**，**停售不在其中**。短期健康险另有监管明文：须**在保险期间内继续提供保障服务**、**期间届满时提供转保建议**；主动停售**提前 30 日**披露、被责令停售**3 日内**披露。⚠️「转保建议」是**服务义务不是承保承诺**，新产品仍需重新核保。⚠️「快停售了赶紧买」**是营销话术不是事实判断**——停售原因多样，可能恰恰是违规被责令。⚠️ 该监管文件**适用范围为短期健康险**，不得直接套用于长期重疾/终身寿/年金 |
| [交不起保费了，保单会不会直接作废？](qa/cannot-pay-premium-what-happens.md) | **不会立刻作废**——《保险法》**第三十六条**给了法定缓冲：**催告后三十日**或**超过约定期限六十日**才进入效力中止，且**这段期限内出险照赔**、只扣欠交保费。中止后**两年内**可协商复效（**第三十七条**），满两年保险人有权解除、**应退还现金价值**。⚠️ 两个常见误解：条文前置「**除合同另有约定外**」，**没有适用于所有保单的天数**，60 天是行业做法不是法律保证；复效要「**协商并达成协议**」，**需保险人同意**、通常要重新健康告知，「两年内随时能复效」不准确。真正危险的是**中止期**——保单还在但不保。⚠️ 本条属**人身保险合同**（第二章第二节），不适用财产险与境外保单 |
| [退保到底能拿回多少钱？为什么跟交的保费差那么多](qa/how-much-do-you-get-back-when-you-surrender.md) | **退保退的是「现金价值」，不是「已交保费」**——《保险法》**第四十七条**：三十日内、**按合同约定**退还保单现金价值。前几年差很多是**结构性结果不是罚你**：保费要摊销获取成本、并支付你已实际获得的保障。**每一年是多少，合同里的现金价值表投保当天就写死了**。不退保拿钱三条路：**减保**（保障永久降低）／**保单贷款**（计息、影响给付）／**部分领取**（仅部分产品）。分红险「能否拿回本金」分两半：**保证部分可查表，非保证部分无人有资格给确定答案**。⚠️ 犹豫期内规则不同。三十秒动作：**打开现金价值表，看今年多少、哪一年超过已交保费** |
| [有人用一个生效日期催我投保，这个理由成立吗？](qa/is-a-deadline-a-reason-to-buy-insurance.md) | **生效日期是公共事实，不是个人依据**——同一日期对所有人相同，而"该不该现在买"因人而异，**一个对所有人相同的事实解释不了一个因人而异的结论**。四类主张四个查证位置：涨价→查**定价条款**；新规生效→查**发布主体与推行方式**（行业自律≠监管强制，**性质弄错则后续推论全错**）；都一样→查**范围限定语＋是否最低标准**；更严→查**有没有逐项列差异**。⚠️**存量与续保强度不同**（"不得单方面"vs"预期不会"）。检验法：**把日期拿掉再问一次** |
| [重疾险赔过一次之后，保单还剩什么？在文件哪里能查到](qa/what-remains-after-a-critical-illness-claim.md) | 赔付不是终点，是保单**换了一套规则继续走**。一次赔付**同时改动五样**：往后保费／身故保障／现金价值／终期红利／后续危疾保障。多数产品的轻症赔付是**「预支」不是「额外」**（现时保额＝原有保额−已预支），少数设**保额还原**。**赔后是否仍有身故保障是"有与无"之别**。查两处：文件后段**「保障终止」**一节 ＋ 摘要表下方**编号注释**；搜「豁免」「终止」「身故」三个词。⚠️「保障终身／至100岁」与「后续赔付至85岁」常是同一份文件上的两个数 **含六款实测三处相反差异**：赔后留不留身故保障是"有与无"之别（一款留投保额20%，两款明写不再提供）；部分赔付后保费一款跟着降、一款明写不降；五款单向扣减、一款设保额还原。 |
