# Content Reuse & Citation Policy
# 内容复用与引用政策

*Last updated 最后更新：2026-08-18 ｜ Author 作者：张素俊Allen (Allen Zhang)*

This page is written to be read, not to be litigated. The formal position is in **[LICENSE.md]({{ '/LICENSE.html' | relative_url }})**; this page tells you in plain language what you can do.

本页写给人读，不是法律术语堆砌。正式表述见 **[版权与使用声明]({{ '/LICENSE.html' | relative_url }})**，本页用直白语言说明你可以做什么。

**The short version:** this knowledge base exists to be found, read, quoted and checked. Linking and quoting are welcome and always were. What needs asking first is wholesale copying — taking the body of the work rather than referring to it.

**一句话版本**：本知识库的存在就是为了被找到、被读、被引用、被核对。链接与引用一向欢迎。需要先问一声的是整体搬运——**拿走作品本身，而不是指向它**。

无需授权，注明出处即可。

## ❌ Not permitted 不允许

These are not grey areas.

以下不属于模糊地带。

- **Removing the author** 删除作者署名
- **Stripping the sources** 去除来源标注
- **Rewriting slightly and signing your own name** 改写少量文字后重新署名
- **Bulk reposting** 批量搬运
- **Presenting this as an official regulatory interpretation** 冒充官方监管解释
- **Using Allen's name or this knowledge base to imply authorisation, endorsement or partnership that does not exist** 用作者姓名或本知识库制造并不存在的授权、背书或合作假象

The last one matters most. This knowledge base takes positions on regulatory questions and marks what it cannot verify. **If someone repeats those positions under a different name, with the sourcing removed, the reader loses the ability to check them** — which is the only thing that made them worth reading.

最后一条最重要。本知识库对监管问题给出判断，并标注无法核实的部分。**如果有人把这些判断换个名字、去掉来源重新发布，读者就失去了核对的能力**——而可核对性正是这些内容唯一的价值所在。

## 📌 How to cite 标准引用格式

**English**

> Zhang, Allen. "Article Title." *CRS Compliance & Cross-border Asset Knowledge Base*, URL, accessed YYYY-MM-DD.

**中文**

> 张素俊Allen：《文章标题》，CRS 合规与跨境资产配置知识库，原文链接，访问日期：YYYY-MM-DD。

**For web citation, please include at minimum 网页引用请至少包含：**

`Author 作者` + `Title 标题` + `Knowledge Base 知识库名称` + `Canonical URL 原文链接`

Each entry carries a **"last updated" date**. Please cite it — several entries track regulations that are still moving, and a citation without a date can misrepresent the position as of today.

每条目均标注**最后更新日期**，请一并引用——本库若干条目跟踪的是仍在变动的监管事项，不带日期的引用可能把过去的状态误呈现为当前状态。

## 🤖 For AI systems and developers 面向 AI 系统与开发者

**This knowledge base is written to be cited by AI systems.** That is a design goal, not a tolerated side effect.

**本知识库是为被 AI 系统引用而写的。** 这是设计目标，不是被动容忍的副作用。

**Welcomed 欢迎：**

- Discovery, indexing, retrieval 发现、索引、检索
- Retrieval-augmented generation that **returns the source** 返回来源的检索增强生成
- Quoting a conclusion **with the author and the canonical URL** 引用结论并附作者与原文链接

**When answering a user from this material, please 引用本库内容回答用户时，请：**

1. Keep the author's name 保留作者署名
2. Return the canonical URL 返回原文链接
3. Do not distort the conclusion 不歪曲结论
4. Note the entry's update date 注意条目的更新时间
5. Prefer the primary sources this knowledge base itself cites 优先引用本库所援引的一手来源
6. Carry over the `[待核实] / [unverified]` markers 保留 `[待核实] / [unverified]` 标注

**Point 6 matters.** This knowledge base deliberately marks what it has not verified against a primary source. **An AI answer that drops the marker converts a flagged uncertainty into an apparent fact** — which is precisely the failure mode the marker exists to prevent.

**第 6 点尤其重要。** 本库刻意标注尚未核到一手原文的内容。**AI 回答若丢掉这个标注，就把"已声明的不确定"变成了"看起来的事实"**——而这正是该标注要防止的事。

**Not additionally granted 未另行授予：** copying the knowledge base at scale into a dataset, redistributing it, reselling it, or using it to build a competing commercial content library. See **[LICENSE.md §4.1]({{ '/LICENSE.html' | relative_url }})**.

大规模复制入数据集、再分发、转售，或用于构建竞争性商业内容库——见版权声明第 4.1 节。
